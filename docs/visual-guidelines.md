# Visual Guidelines

Every parameter graphic should explain one variable while keeping all unrelated conditions constant.

## Standard format

- 16:9 PNG output.
- Dark chart background consistent with TradingView.
- Exact candle counts and mathematically correct proportions.
- Green for accepted conditions and red for rejected conditions.
- Measurement lines anchored to explicit OHLC values.
- A short formula or rule beneath the visual.
- No decorative candles that could be mistaken for part of a formation.

## Comparison principle

When explaining a threshold, the preferred graphic uses the same candle or formation on both sides. Only the documented input value changes.

## Validation

Visual examples must be derived from deterministic values or machine-readable OHLCV data. Screenshots may illustrate the result but must not be used as the source for exact zone boundaries.
