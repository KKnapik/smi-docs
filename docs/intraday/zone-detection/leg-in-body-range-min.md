# Leg-In Body/Range Minimum

**Default:** `0.50`

This parameter defines the minimum portion of the complete leg-in candle range that must be occupied by the candle body.

```text
Leg-In body ≥ Leg-In range × minimum ratio
```

A lower value permits candles with larger wicks. A higher value requires a cleaner directional candle.
