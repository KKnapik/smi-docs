# Leg-In Body vs Base

**Default:** `1.50`

This parameter requires the leg-in body to be larger than the largest body found inside the base.

```text
Leg-In body ≥ Largest base body × Leg-In Body vs Base
```

A lower value permits weaker re-accumulation and re-distribution structures. A higher value requires a more visually distinct leg-in.

## Planned visual

The largest base body will be used as a measurement unit and compared directly with accepted and rejected leg-in candles.
